# 📚 مساعد التقارير — منصة ذكاء اصطناعي متخصصة في تقارير قطاع معيّن

منصة ويب بـ **PHP خام** تحوّل أرشيف التقارير السنوية لإدارة عمومية (مثال: **التعمير** — عشرون سنة من تقارير الأنشطة) إلى:

| | |
|---|---|
| 📂 **كل صيغ ملفاتكم** | **PDF**، **Word** (‎.docx ‎.doc)، **Excel** (‎.xlsx ‎.xls ‎.csv)، **PowerPoint** (‎.pptx ‎.ppt) — في الإدخال، والتصدير إلى Word وExcel وPowerPoint |
| 🔎 **قاعدة معرفة قابلة للسؤال** | اسأل بالعربية أو الفرنسية: «كم عدد رخص البناء سنة 2012؟»، «ما تطور المخالفات منذ 2005؟» — جواب مع **المصدر (السنة والصفحة)** |
| 📊 **قاعدة إحصائيات عبر السنوات** | كل الأرقام مستخرجة من التقارير، موحَّدة بين السنوات واللغتين، مع رسم بياني ونسب التطور وتصدير إلى Excel |
| ✍️ **تحرير تقارير جديدة** | التقرير السنوي للسنة الجديدة بنفس هيكلة وأسلوب التقارير السابقة مع مقارنات تاريخية، أو تقرير موضوعاتي حول موضوع عبر فترة — تنزيل Word |

## 💡 لماذا ليس «تدريب» نموذج؟

تدريب نموذج على 20 تقريراً مكلف، ولا يضمن حفظ الأرقام بدقة، ويجب إعادته مع كل تقرير جديد. المنصة تعتمد طريقة أدق وأرخص:

1. **قراءة كل تقرير مرة واحدة** وتقسيمه إلى مقاطع مفهرسة للبحث (بالعربية والفرنسية).
2. **استخراج الأرقام** بالذكاء الاصطناعي إلى جدول: المؤشر، السنة، القيمة، الوحدة، **الصفحة، والجملة الأصلية**.
3. **التحقق الآلي**: كل رقم يُبحث عنه حرفياً في صفحته؛ وإن لم يوجد يُعلَّم «⚠ للتحقق».
4. **توحيد المؤشرات**: «عدد رخص البناء المسلمة» (2008) و«Autorisations de construire délivrées» (2015) = مؤشر واحد.
5. عند السؤال، يستعمل Claude **أدوات** للبحث في هذه القاعدة، ويجيب فقط مما وجده مع ذكر المصدر. الحسابات (نسب التطور، معدل النمو…) تُحسب **برمجياً** لا من ذاكرة النموذج.

إضافة تقرير سنة جديدة = رفعه فقط، بدون إعادة أي «تدريب».

## ⚙️ التثبيت

**بدون Composer وبدون أي مكتبة خارجية:** كل الكود PHP خام. قراءة وكتابة Word وExcel وPowerPoint مكتوبة داخل المشروع، والاتصال بـ Claude يتم عبر `curl` مباشرة. ارفع المجلد كما هو.

**المتطلبات:**
- PHP **8.1+** مع الإضافات: `pdo_sqlite` (بدعم FTS5، متوفر افتراضياً)، `curl`، `mbstring`، `zip`، `dom`، `xmlreader` — كلها مفعّلة عادة في cPanel (‏«Select PHP Version» ← Extensions)
- **poppler-utils** (الأوامر `pdftotext` و`pdfinfo`) لقراءة ملفات **PDF** فقط. تحقّق في Terminal: `which pdftotext`. إن لم يكن موجوداً على الاستضافة المشتركة: اطلب تثبيته من مزوّد الاستضافة، أو عالج ملفات PDF على حاسوبك (انظر أسفله). ملفات Word وExcel وPowerPoint لا تحتاجه.
- **LibreOffice** (اختياري) لملفات ‎.doc و‎.ppt القديمة فقط. ‎.xls القديمة تُقرأ بدونه.
- مفتاح [Anthropic API](https://console.anthropic.com)، أو نموذج محلي (انظر «نموذج محلي»).

**التثبيت على cPanel:**
1. ارفع مجلد `reports-ai` (مضغوطاً ثم «Extract» في File Manager) إلى `/home/حسابك/reports-ai`.
2. أنشئ نطاقاً فرعياً (مثلاً `rapports.domaine.ma`) وجذره **`reports-ai/public`** فقط.
3. انسخ `.env.example` إلى `.env` وضع فيه `ANTHROPIC_API_KEY` (أو إعدادات النموذج المحلي).
4. في Terminal (أو SSH):
```bash
cd ~/reports-ai
chmod 775 storage
php bin/user.php admin admin                 # مسؤول (يضيف ويحذف التقارير)
php bin/user.php fatima user                 # مستخدم (يسأل، يطّلع على الإحصائيات، يحرّر تقارير)
```
5. في «Cron Jobs»: كل دقيقة `php /home/حسابك/reports-ai/bin/worker.php > /dev/null 2>&1` (قد يكون المسار `/usr/local/bin/php`).

**بدون pdftotext على الاستضافة:** شغّل «خدمة قراءة الملفات» على حاسوبك (القسم التالي).

### 📄 خدمة قراءة الملفات على حاسوبك

الاستضافة المشتركة لا تتوفر غالباً على `pdftotext` (لملفات PDF) ولا على LibreOffice (لملفات ‎.doc و‎.ppt القديمة). الحل: حاسوبك يقرأ هذه الملفات، والاستضافة تفعل كل الباقي.

```
الاستضافة ──(الملف)──▶ القناة (Cloudflare) ──▶ خدمة القراءة على حاسوبك (PHP + pdftotext)
          ◀──(النص صفحة صفحة)──
```

**على Windows:**
1. حمّل المشروع على حاسوبك (GitHub ← Code ← Download ZIP) وفكّ الضغط.
2. شغّل `reports-ai\extractor\start-windows.bat` (نقرة مزدوجة).
   في أول مرة يحمّل وحده ما ينقص في `extractor\tools`: PHP، وpoppler (‏pdftotext)، وcloudflared.
3. تظهر في النافذة سطران (ومنسوخان في الحافظة):
   ```
   RAI_EXTRACT_URL=https://xxxx.trycloudflare.com
   RAI_EXTRACT_KEY=…
   ```
   ضعهما في ملف `.env` على الاستضافة، ثم تحقّق: `php bin/local-check.php`.
4. **اترك النافذة مفتوحة** ما دمت تضيف تقارير. بعد إدخال التقارير لم تعد الخدمة ضرورية: البحث والأسئلة والإحصائيات تعمل من الاستضافة وحدها.

**على Linux / macOS:** ثبّت `php` و`poppler-utils` (أو `brew install poppler`) و`cloudflared`، ثم `./extractor/start.sh`.

**ملاحظات:**
- رابط `trycloudflare` يتغيّر في كل تشغيل → حدّث `RAI_EXTRACT_URL`. لرابط ثابت: قناة Cloudflare باسم نطاقك.
- المفتاح يُنشأ مرة واحدة ويُحفظ في `extractor/key.txt` (لا يُرفع إلى GitHub). لتغييره احذف الملف وأعد التشغيل.
- لا يُحفظ أي ملف على حاسوبك: يُقرأ ثم يُحذف فوراً.
- LibreOffice (اختياري) على حاسوبك يكفي لملفات ‎.doc و‎.ppt القديمة.
- إذا كانت الخدمة متوقفة أثناء إضافة تقرير، يظهر خطأ واضح؛ شغّلها ثم اضغط «إعادة» أمام التقرير.
- `RAI_EXTRACT_REMOTE=always` يرسل كل ملفات PDF إلى حاسوبك حتى لو توفرت pdftotext على الاستضافة.


**الاستضافة:** جذر الموقع هو المجلد `public/` فقط. ملف `.htaccess` جاهز لـ Apache.

**المهام الخلفية:** معالجة تقرير أو تحرير تقرير جديد تستغرق دقائق، فتُنفَّذ في الخلفية بمهمة cron السابقة. تبدأ المنصة المعالجة فوراً إن كان `exec` مسموحاً على الخادم، وcron احتياط.

**إضافة التقارير الـ20 دفعة واحدة من سطر الأوامر:**
```bash
for f in /chemin/rapports/*.{pdf,docx,xlsx,pptx}; do
  year=$(echo "$f" | grep -oE '(19|20)[0-9]{2}' | head -1)
  php bin/worker.php --ingest "$f" --year "$year"
done
php bin/worker.php          # يعالج كل التقارير في الانتظار
```

## 🖥️ تشغيل المنصة كاملة على حاسوبك (Apache: XAMPP أو WAMP)

إذا اشتغلت المنصة على حاسوبك نفسه، فلا حاجة إلى القناة ولا إلى خدمة قراءة الملفات: `pdftotext` والنموذج المحلي على نفس الجهاز.

1. **Apache وPHP:** ثبّت [XAMPP](https://www.apachefriends.org) (PHP 8.1 أو أحدث). في XAMPP Control Panel اضغط Start أمام Apache: يجب أن يصبح أخضر، و`http://localhost` يعرض صفحة XAMPP. (إن لم يبدأ: المنفذ 80 مستعمل من برنامج آخر، استعمل 8080 كما في الخطوة 3.)
2. **php.ini** (Control Panel ← Apache ← Config ← PHP (php.ini)): احذف `;` من أول هذه الأسطر، ثم عدّل الحجم:
   ```ini
   extension=curl
   extension=mbstring
   extension=pdo_sqlite
   extension=zip
   upload_max_filesize = 64M
   post_max_size = 70M
   ```
3. **الموقع:** ضع المجلد في `E:\reports-ai`، وأضف في آخر `C:\xampp\apache\conf\extra\httpd-vhosts.conf`:
   ```apache
   Listen 8080
   <VirtualHost *:8080>
       DocumentRoot "E:/reports-ai/public"
       <Directory "E:/reports-ai/public">
           AllowOverride All
           Require all granted
       </Directory>
   </VirtualHost>
   ```
   أعد تشغيل Apache، ثم افتح `http://localhost:8080`.
4. **`.env`** (انسخه من `.env.example`):
   ```
   ANTHROPIC_API_KEY=…                      # أو النموذج المحلي مباشرة، بدون قناة:
   # RAI_PROVIDER=local
   # RAI_LOCAL_URL=http://127.0.0.1:11435
   RAI_POPPLER_DIR=E:\reports-ai\extractor\tools\poppler\poppler-24.08.0\Library\bin
   RAI_PHP_CLI=C:\xampp\php\php.exe
   ```
   `RAI_POPPLER_DIR` هو المجلد الذي فيه `pdftotext.exe` (حمّله `start-windows.bat` في `extractor\tools\poppler`؛ رقم النسخة قد يختلف). لا تضع `RAI_EXTRACT_URL`.
5. **المسؤول:** في نافذة أوامر داخل `E:\reports-ai`:
   ```bat
   C:\xampp\php\php.exe bin\user.php admin admin
   C:\xampp\php\php.exe bin\local-check.php
   ```
6. **المعالجة في الخلفية** تبدأ وحدها بعد كل رفع. احتياطاً (مثلاً بعد إعادة تشغيل الحاسوب): `C:\xampp\php\php.exe bin\worker.php` يعالج ما بقي في الانتظار.

## 🛡️ الدقة والثقة

- **مصدر لكل رقم**: الأجوبة والتقارير المحرَّرة تذكر (السنة · الصفحة) لكل معلومة، والرابط يفتح نص الصفحة الأصلية.
- **تحقق آلي** من كل رقم مستخرج في صفحته، مع علامة «⚠ للتحقق» عند الشك.
- **لا اختراع**: النموذج مُوجَّه ليجيب فقط من القاعدة، ويكتب «[معطى يجب استكماله]» عند غياب المعلومة.
- **تضارب القيم** بين تقريرين لنفس السنة يظهر صراحة.
- **تصحيح النص العربي**: بعض ملفات PDF تُستخرج منها «لا» مقلوبة («خلال» ← «خالل»). المنصة تكتشف ذلك تلقائياً وتصحّحه، مع **ضمان برمجي**: لا يُقبل التصحيح إلا إذا كان التغيير الوحيد هو ترتيب «لا»؛ أي تغيير آخر (رقم، كلمة) يُرفض ويُحتفظ بالنص الأصلي.

## 🖥️ نموذج محلي على حاسوبك (Ollama)

يمكن أن يجيب نموذج مثبت على حاسوبك بدل Claude، لكل المهام أو لبعضها فقط، **بدون كلفة لكل طلب** والملفات لا تخرج إلى مزوّد خارجي.

```
المنصة (الاستضافة)  ──HTTPS──▶  القناة (Cloudflare Tunnel)  ──▶  البوابة (مفتاح)  ──▶  Ollama على حاسوبك
```

**الإعداد في `.env`:**
```
RAI_PROVIDER=local                                  # كل المهام على النموذج المحلي
RAI_LOCAL_URL=https://xxxx.trycloudflare.com        # رابط القناة (لا 127.0.0.1: الاستضافة لا تصل إلى حاسوبك مباشرة)
RAI_LOCAL_MODEL=qwen3.5:4b                          # اسم من «ollama list»
RAI_LOCAL_KEY=…                                     # مفتاح البوابة — في .env فقط، لا في الكود
```
أو **إعداد مختلط** (مقترح): `RAI_PROVIDER=anthropic` مع `RAI_PROVIDER_REPAIR=local` و`RAI_PROVIDER_EXTRACT=local`… لكل مهمة على حدة.
ثم تحقّق من الاتصال: `php bin/local-check.php` (يعرض المهام، النماذج المثبتة، ويرسل رسالة تجريبية).

**شروط يجب معرفتها:**
- **الحاسوب وOllama والقناة يجب أن تبقى مشغّلة.** إذا توقفت، تتوقف معالجة التقارير والأسئلة برسالة واضحة، والتقارير تُعاد معالجتها بزر «إعادة».
- **رابط `trycloudflare.com` المؤقت يتغيّر عند كل تشغيل للقناة** → حدّث `RAI_LOCAL_URL` كل مرة، أو أنشئ قناة Cloudflare دائمة باسم نطاقك (مثلاً `ai.kidsnotices.ma`).
- **احمِ البوابة بمفتاح**، ولا تنشره. غيّره إذا ظهر في رسالة أو صورة.
- النماذج الصغيرة على المعالج (CPU) بطيئة: صفحات الأسئلة محدودة بـ 300 ثانية؛ المعالجة في الخلفية بدون حدّ (`RAI_LOCAL_TIMEOUT`).
- يُرسل حجم السياق `RAI_LOCAL_CONTEXT` (افتراضياً 16384) لأن Ollama يقطع النصوص الطويلة بصمت بدونه؛ إذا كان النص أطول، تظهر رسالة بدل جواب ناقص.

**الجودة حسب حجم النموذج** (تقدير؛ جرّب على تقاريرك):

| المهمة | نموذج 3–4 مليار (qwen2.5:3b، qwen3.5:4b) | نموذج 14–32 مليار (مثلاً qwen3:14b، qwen2.5:32b) |
|---|---|---|
| تصحيح «لا» (`repair`) | مقبول — كل تصحيح يغيّر شيئاً آخر يُرفض تلقائياً | جيد |
| الملخص والفهرس | مقبول | جيد |
| استخراج الأرقام (`extract`) | ضعيف: أرقام ناقصة، وأرقام خاطئة تُعلَّم «⚠ للتحقق» | جيد |
| توحيد المؤشرات (`map`) | ضعيف (خلط بين المؤشرات) | مقبول إلى جيد |
| الأسئلة بالأدوات (`ask`) وتحرير التقارير (`report`) | **غير مقترح**: عربية ضعيفة، أخطاء في استعمال الأدوات | مقبول؛ Claude أفضل بكثير |

الحماية تبقى نفسها مع أي نموذج: كل رقم يُتحقق منه في نص الصفحة، والأرقام الإحصائية تُحسب على الخادم لا بالنموذج.

## 🔁 لقطاع آخر غير التعمير

المنصة عامة. كل ما يخص القطاع في ملف واحد: [`config/domain.php`](config/domain.php)
- اسم الإدارة والقطاع بالعربية والفرنسية،
- **أصناف الأرقام** (التخطيط، الرخص، المراقبة…)،
- **قاموس المصطلحات** عربي ↔ فرنسي (يساعد على توحيد المؤشرات بين السنوات واللغتين).

انسخه (مثلاً `config/sante.php`)، عدّله، ثم `RAI_DOMAIN_FILE=config/sante.php` في `.env`.

## ⚠️ حدود حالية

- **ملفات PDF نصية فقط**: الملفات الممسوحة ضوئياً (صور) تُرفض برسالة واضحة؛ تحتاج تحويلاً بـ OCR أولاً (مثلاً `ocrmypdf --language ara+fra`).
- الصيغ القديمة ‎.doc و‎.ppt تحتاج LibreOffice على الخادم (وإلا احفظها بصيغة ‎.docx/‎.pptx).
- ملفات Excel الضخمة (أكثر من 30 000 صف) تُرفض: احتفظ بأوراق الملخص.
- الأرقام المستخرجة تعتمد على وضوح التقارير: راجع العلامات «⚠ للتحقق» في صفحة الإحصائيات.

---

## 🔐 الأمان

- الدخول بحساب (كلمات مرور مُجزّأة)، حماية CSRF، ترويسات أمان، `noindex` لمحركات البحث.
- الملفات وقاعدة البيانات في `storage/` خارج جذر الموقع.
- مفتاح Anthropic على الخادم فقط. التقارير ترسل إلى Anthropic API للمعالجة (حسب الشروط التجارية لـ Anthropic، بيانات API لا تُستعمل للتدريب افتراضياً — تحقّق من الشروط الحالية).
- مع النموذج المحلي (`RAI_PROVIDER=local`) تذهب النصوص إلى حاسوبك فقط عبر القناة؛ مفتاح البوابة في `.env` على الخادم فقط.

## 🧪 الاختبارات (بدون كلفة)

```bash
php tests/run.php           # كل المهام على Claude
php tests/run.php --local   # كل المهام على نموذج محلي (Ollama مزيّف)، والعروض على Claude
```
الوضع المحلي (94 اختباراً) يستعمل خادم Ollama مزيّفاً خلف بوابة بمفتاح (`tests/mock_ollama.php`)، ويتحقق أيضاً من الرسائل الواضحة عند خطأ المفتاح، أو نموذج غير مثبت، أو حاسوب/قناة متوقفة، أو نص أطول من السياق.

90 اختباراً على خادم Claude مزيّف (`tests/mock_claude.php`) يتحقق من صحة كل طلب كما يفعل Anthropic (تناوب الرسائل، إرجاع كتل التفكير ونتائج الأدوات، مخططات JSON، خيار fallbacks حسب النموذج) ومن إعادة المحاولة عند انشغال الخدمة، مع ملفات Word وExcel (‎.xlsx و‎.ods و‎.xls القديمة) وPowerPoint أنشأتها برامج أخرى في [`tests/fixtures/`](tests/fixtures/)، باستعمال **4 تقارير تجريبية وهمية** في [`samples/`](samples/) (عربية وفرنسية):
إدخال التقارير، ملفات Word وExcel وPowerPoint و‎.doc القديمة (تُنشأ أثناء الاختبار)، تصحيح «لا» ورفض التصحيح غير الآمن، توحيد المؤشرات بين اللغتين، الإحصائيات والحسابات، البحث، المساعد بالأدوات، تحرير التقارير وتصدير Word وExcel (مع الرسم البياني) وPowerPoint (مع رفض رسم يحتوي رقماً غير موجود في التقرير)، الرفع من الصفحة والمعالجة في الخلفية، خدمة قراءة الملفات على الحاسوب (نفس الصفحات، المفتاح الخاطئ، الخدمة المتوقفة)، رفض الملفات الممسوحة، الحذف، والصفحات (الدخول، الصلاحيات، CSRF، CSV).
